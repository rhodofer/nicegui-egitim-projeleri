## 🛠️ Kurulum & Çalıştırma

### 1. Gereksinimleri Yükleyin
Projeyi yerel ortamınızda çalıştırmak için Python 3.9+ gereklidir. Gerekli kütüphaneyi yüklemek için:

```bash
pip install -r requirements.txt
```

*(veya doğrudan: `pip install nicegui`)*

### 2. İlgili Dersi Çalıştırın
Herhangi bir dersi çalıştırmak için terminalden dosyanın bulunduğu dizine geçip Python ile başlatabilirsiniz:

```bash
cd NiceGUIProjects
python Ders1.py
```

Tarayıcınızda otomatik olarak `http://localhost:8080` adresinde uygulama açılacaktır.
